# 💼 Mahesh Raja - Portfolio Website

This is my personal portfolio website built using **Angular**. It showcases my projects, technical skills, resume, and contact information. Designed to be responsive and deployed using **GitHub Pages**.

## 🚀 Live Demo

🌐 [Visit Portfolio](https://maheshraja2oo2.github.io/Portfolio/)

## 🛠️ Built With

- [Angular](https://angular.io/)
- HTML & CSS
- GitHub Pages (for hosting)

## 📁 Features

- ✨ Responsive design
- 🧩 Project showcase with GitHub links
- 📄 Resume section
- 📬 Contact details and social media links

## 📦 Installation

To run locally:

```bash
git clone https://github.com/maheshraja2oo2/Portfolio.git
cd Portfolio
npm install
